# islam-kit — Sabil Nour

Dépôt de production de la chaîne YouTube Sabil Nour (@SabilNour0u).
Lire d'abord `docs/BIBLE_PRODUCTION_SABIL_NOUR.md`.

- `docs/` bible, instructions, méthode
- `catalogue/` catalogue de tous les contenus
- `scripts/fr`, `scripts/en` scripts et textes de voix off
- `voix/fr`, `voix/en` voix off (ElevenLabs, Sébastien – Narrator, v3)
- `images/par_contenu/<ID>/` images de chaque contenu · `images/banque/` images réutilisables
- `moteur/` modèles HTML et scripts de montage · `sons/` banque de sons · `charte/` logo, polices, fonds
- `miniatures/` miniatures · les MP4 finaux sont dans Google Drive
