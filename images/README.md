# Images
- `par_contenu/<ID>/` : toutes les images d'un contenu, nommées `<ID>_<code d'origine>.png` (codes A1…, L1…, M01…). Les fichiers `cut_*` sont les détourages (rembg) du style apparition.
- `banque/` : réutilisables. Pas encore alimentée : avant de générer une nouvelle image, regarder `par_contenu/` (ex. désert de Bilal repris dans « Le chien et le puits », mont Uhud M18, rayons dorés M26).
- Toute nouvelle image générée par Mo se dépose dans `par_contenu/<ID>/` sur GitHub, jamais collée dans le chat.
